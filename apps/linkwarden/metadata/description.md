# Linkwarden

Save links, organize them in collections and tags, and let Linkwarden archive each page (screenshot, PDF, readable view) so it stays available even if the website disappears.

## First start

Open the app and register. The first start runs database migrations, so give it a minute.

## Notes

The app URL is derived from the domain Runtipi gives it. If you change the domain or toggle HTTPS, restart the app so login keeps working.
